# Accounts Payable Data Analysis Using SQL

## Objective
The objective of this project is to analyze Accounts Payable data using SQL to derive insights related to vendor performance, payment delays, and outstanding liabilities.

## Dataset Description
Dataset Used: Accounts-Payable.csv
It contains information about
- vendor details
- Invoice amounts
- Due dates
- Payment dates
- Payment status
- Delay Days

## Tools Used
- SQL (Joins, CTEs, Aggregations, CASE WHEN Statement)
- SQL Server
- CSV (Data Source)

## Accounts Payable Analytics Performed
The following SQL-based analysis was performed:
- Calculated total overdue payments using conditional aggregations
- Measured payment delays using DATEDIFF() function
- Performed vendor-wise spending analysis using Group By
- Identified high-risk vendors based on average delay days
- Used Joins between Accounts Payable and Vendor data
- Applied CTEs for structured multi-step analysis

## Key Insights
- Analyzed Accounts Payable dataset to evaluate vendor payments, delays and financial outflows.
- Calculated total overdue payments and outstanding liabilities across the dataset
- Performed vendor-wise spending analysis using SQL aggregations
- Evaluated payment delay patterns to assess vendor performance and payment efficiency
- Used Join operations to integrate Accounts Payable and Vendor data for consolidated analysis
- Applied CTEs and aggregations for multi-step financial analysis
